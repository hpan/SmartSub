# 工作台（自动化流水线）

工作台是妙幕的自动化内容生产中心，能够定时监控 B 站指定 UP 主的视频列表，自动识别目标节目并驱动完整的处理流水线——从下载到最终的音画合成，全程可视化管控。

左侧导航点击 **「工作台」** 即可进入。

---

## 核心能力

| 能力             | 说明                                                               |
| :--------------- | :----------------------------------------------------------------- |
| **B 站节目监控** | 定时扫描指定 UP 主最新视频，按规则自动识别目标节目                 |
| **智能节目识别** | 结合发布时间、标题关键词、时长等多维度判断，过滤非目标内容         |
| **自动化流水线** | 下载 → 智能改名 → 静音裁割 → 生成封面 → 上传 IMA 知识库 → 音画合成 |
| **任务看板**     | 卡片式展示即将到来的节目和进行中的任务，带倒计时和进度             |
| **监控日志**     | 完整记录每次扫描结果，支持手动将视频添加到任务队列                 |
| **任务管控**     | 支持开始执行、停止、重试、重置任务                                 |

---

## 节目监控

### 监控机制

- 系统按照预设的时间窗口自动扫描 B 站 UP 主的视频列表
- **大摩系列**（宏观策略谈、周期论剑、新经济热点前瞻）：周一、三、五，中午 12 点后开始监控
- **中金宏观策略周论**：周一，与大摩周一节目同期监控
- **招商宏观周周谈**、**华创宏观张瑜旬度**：周日晚 21 点后开始监控
- 监测到目标节目后当天停止扫描，避免重复
- 监控频率：测试期每 5 分钟一次，正式运行每 30 分钟一次

### 节目识别规则

系统通过以下维度综合判断：

1. **发布日期**：匹配各节目的固定播出日（周一/三/五/日）
2. **发布时间**：大摩/中金为中午后发布，招商/华创为晚间发布
3. **标题关键词**：如"大摩"、"中金"、"招商"、"张静静"、"华创"、"张瑜"等
4. **视频时长**：排除过短的视频（如研报 AI 合成视频），通常要求 30 分钟以上

### 手动添加任务

在监控日志中，每条记录右侧有 **「+」** 按钮，点击可将该视频手动添加到任务队列，即使未被自动规则匹配到。

## 任务流水线

每个任务按以下步骤依次执行：

| 步骤     | 说明                                                      |
| :------- | :-------------------------------------------------------- |
| **下载** | 从 B 站下载音频文件，实时显示下载进度                     |
| **改名** | 按 `{日期}-{栏目名}：{标题}` 格式智能重命名，支持手动修改 |
| **裁割** | 自动去除音频首尾静音段                                    |
| **封面** | 自动生成节目封面图，保存至节目的 `Cover` 子目录           |
| **IMA**  | 上传至 IMA 知识库对应目录                                 |
| **音画** | 调用音画合成功能生成最终可视化视频                        |

:::tip 流程可中断
在任意步骤可以点击「停止」终止整个流水线。失败的任务支持「重试」从头重新执行。
:::

## 任务看板

工作台顶部的任务卡片以时间线形式展示：

- **即将到来**：最近待处理的节目，显示节目名称、播出日、倒计时
- **倒计时精度**：精确到分钟级别，临近的节目用不同底色标识
- **进行中任务**：显示当前正在执行的步骤和整体进度
- **已完成任务**：标记为完成状态

### 卡片信息

每个任务卡片包含：

- 节目名称（完整名称，如"大摩宏观策略谈"、"华创宏观张瑜旬度"）
- 播出日期和时间
- 倒计时（距离预计处理时间还有多久）
- 临近程度配色标识

---

## 监控日志

界面底部固定区域展示监控日志，自动展开，支持滚动查看。

每条日志包含：

- **扫描时间**：精确到分钟，格式如 `10/13 12:30`
- **视频标题**：截断显示前 40 个字符，超长部分以省略号替代
- **BV 号**：标题后括号内显示
- **发布时间**：视频在 B 站的发布日期和时间（双位对齐格式）
- **操作图标**：
  - 链接图标：点击用默认浏览器打开 B 站视频页面
  - 复制图标：点击复制视频标题
  - 添加按钮（+）：将该视频添加到任务队列

日志仅记录新发现的视频，已扫描过的不重复显示。

## IMA 知识库上传

下载完成的节目可一键上传至 IMA 知识库。系统根据节目名称自动路由到对应的知识库目录：

| 节目             | IMA 知识库目录                |
| :--------------- | :---------------------------- |
| 大摩闭门会       | 大摩闭门会知识库              |
| 中金宏观策略周论 | 中金闭门会 / 中金宏观策略周论 |
| 招商宏观周周谈   | 招商宏观周周谈                |
| 华创宏观张瑜旬度 | 华创宏观张瑜旬度              |
