# 工坊（多功能工具箱）

工坊是妙幕内置的多功能音视频处理工具集，将日常高频的轻量处理操作整合在一个界面中，拖拽文件即可开始操作。

左侧导航点击 **「工坊」** 即可进入，顶部通过标签页切换不同工具。

---

## 标签页一览

| 标签     | 功能              | 核心能力                                                          |
| :------- | :---------------- | :---------------------------------------------------------------- |
| **裁割** | 音频智能裁切      | 波形可视化 + 静音检测，键盘精确控制切割点，适合去除片头片尾静音段 |
| **裁片** | 视频手动裁切      | 逐帧预览 + 键盘方向键精确定位，设置起止时间后预览裁切区间         |
| **变速** | 音频/视频倍速调整 | 预设倍速（1.1x ~ 2x）或自定义，实时试听，计算变速后时长           |
| **提取** | 从视频中提取音频  | 支持多种音频格式输出，适合为后续字幕转写准备音频素材              |
| **祛印** | 视频水印去除      | 智能检测并去除视频中的水印                                        |

## 裁割（音频智能裁切）

专为音频文件设计的裁切工具，常见用途是去除播客、录音等音频前后多余的静音段。

- **拖拽上传**：将音频文件拖入区域即可加载
- **波形可视化**：加载后自动展示音频波形，静音区域以红色高亮标记
- **智能静音检测**：自动分析片头和片尾，识别可裁切的静音区间
- **键盘精确控制**：
  - `空格` 播放 / 暂停
  - `←` / `→` 方向键逐秒移动光标
  - 上下方向键微调起止时间（100ms 步进）
- **频谱展示**：支持查看音频频谱图辅助判断
- **试听预览**：设置切割点后可预览裁切效果

## 裁片（视频手动裁切）

用于裁剪视频前后不需要的片段（如广告、片头等），需要人工判断起止位置。

- **逐帧预览**：视频加载后可逐帧查看画面内容
- **键盘操作**：
  - `空格` 播放 / 暂停
  - `←` / `→` 方向键逐秒移动
  - 起始 / 截止时间输入框支持上下键微调（100ms 步进）
- **设置起止时间**：分别设定裁切的起点和终点
- **预览区间**：点击「预览」按钮仅播放选定区间，确认无误后提交裁切
- **独立播放**：裁片的预览播放与主播放器完全独立，互不干扰

## 变速（倍速调整）

将音频或视频以指定倍速播放并导出新文件。

- **预设倍速**：提供 1.1x、1.25x、1.35x、1.5x、2x 常用档位
- **自定义倍速**：支持手动输入任意倍速值
- **实时试听**：选定倍速后可直接播放试听效果
- **时长预览**：自动计算变速后的最终文件时长
- **空格控制**：按空格键播放 / 暂停试听
- **提交生成**：确认满意后提交，生成变速后的新文件

## 提取（音频提取）

从视频文件中快速抽取音轨，为字幕转写等后续流程准备纯音频素材。

- 拖拽视频文件即可提取
- 支持多种输出格式

## 祛印（水印去除）

智能检测并去除视频画面中的水印。

- 拖拽视频文件即可处理
- 自动检测水印位置
