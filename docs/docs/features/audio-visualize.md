# 音画合成（音频可视化）

将纯音频内容（播客、财经解读、有声读物等）与背景图合成为带有动态频谱动画的可视化视频，让音频内容具备视觉表现力，适合在 B 站、YouTube 等视频平台发布。

## 核心能力

| 能力           | 说明                                                               |
| :------------- | :----------------------------------------------------------------- |
| **频谱动画**   | 音频频谱随音频节奏动态展示，让画面"动起来"                         |
| **背景图管理** | 支持上传多张背景图，按节目独立配置，支持拖拽排序                   |
| **Logo 管理**  | 支持多个 Logo 叠加，可命名标注，支持拖拽排序和设置默认             |
| **标题与字幕** | 自动显示音频标题，支持外挂字幕文件，标题换行与最终视频一致         |
| **文字水印**   | 平铺式文字水印防伪，可配置密度、角度、透明度                       |
| **免责声明**   | 可配置文字内容、位置（九宫格）和透明度                             |
| **节目配置**   | 按节目（如"大摩闭门会"、"神秘大佬"）独立保存封面、Logo、水印等参数 |

---

## 使用方式

### 1. 选择背景图

- 在节目配置中上传背景图，支持多张
- 在音画主界面点击缩略图选中当前要用的背景图
- 背景图支持拖拽排序

### 2. 管理 Logo

- 在节目配置中上传 Logo，支持多个并可命名（如"大摩"、"中金"）
- 点击 Logo 缩略图可设为默认，默认 Logo 优先用于预览与视频生成
- Logo 支持配置显示位置（左上、右上、左下、右下等）

### 3. 加载音频文件

- 拖拽或选择音频文件
- 系统自动读取音频时长、格式等信息（异步加载，不阻塞界面）

### 4. 配置字幕（可选）

- 可加载外挂字幕文件（SRT 等）
- 字幕会叠加到视频画面中，支持描边和阴影效果

### 5. 水印与免责声明

- **水印开关**：可全局开启/关闭水印；节目级别可独立配置默认开关状态
- **水印文字**：在通用样式中配置全局水印文字，节目级别可覆盖
- **水印参数**：密度、角度（默认 -45°）、透明度均可在通用样式设置中调整
- **免责声明**：配置文案、位置和透明度；底部居中时自动留出距边缘的安全距离
- 水印使用「钉钉进步体」字体

### 6. 预览与生成

- 右侧实时预览窗口展示标题、字幕的显示效果
- 预览中的标题换行位置与最终生成视频完全一致
- 点击「生成视频」开始合成

---

## 节目配置

节目配置是音画合成的核心管理模块，按节目名称独立保存所有视觉参数。

- 左侧导航点击 **「节目配置」** 进入
- 每个节目可独立配置：背景图、Logo、水印开关、水印文字等
- 在音画主界面选择节目后，点击「节目配置」会自动定位到对应节目
- 支持添加、删除节目

:::tip 节目级配置优先
如果节目级别设置了水印文字，则使用节目自己的水印；如果为空，则使用通用样式中的全局水印文字。水印开关同理。
:::

---

## 通用样式设置

通用样式管理全局默认的视觉参数，位于节目配置页面或单独入口。

- **字幕样式**：字体、字号、颜色、描边、阴影
- **水印参数**：水印文字、密度、角度、透明度
- **免责声明**：文案、位置、透明度
